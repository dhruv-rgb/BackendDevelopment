## 🚀 How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/dhruv-rgb/BackendDevelopment.git
cd BackendDevelopment
```

### 2. Run Lab Experiments
- **Experiment 01**: Open `lab/Exp_01/code.html` directly in your browser.
- **Experiment 12 (A)**:
  ```bash
  cd lab/Exp12_A
  npm install
  node app.js
  ```
- **Experiment 12 (B)**:
  ```bash
  cd lab/Exp12_B
  npm install
  node session-cookie-demo/server.js
  ```

### 3. Run Theory Tasks
- **Task 1 (Express & EJS)**:
  ```bash
  cd Theory/Task_1
  npm install
  node server.js
  ```
- **Task 2 (Flask)**:
  ```bash
  cd Theory/Task_2
  python app.py
  ```
- **Task 3 (FastAPI)**:
  ```bash
  cd Theory/Task_3
  python main.py
  ```
