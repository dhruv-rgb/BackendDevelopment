# Experiments 07–08: ES6 Task Board

A browser-based task list demonstrating classes, array spread, destructuring, template strings, and event delegation. Tasks persist in `localStorage`.

## Run

Open `index.html` in a modern browser. No server or package installation is needed. Use the form to add tasks, click a task to mark it complete, and use its Remove button to delete it.

## Concepts

- `Task` class and instance methods
- Array spread for immutable updates
- Destructuring task fields while rendering
- One delegated click listener for the task list
- JSON serialization and browser storage
