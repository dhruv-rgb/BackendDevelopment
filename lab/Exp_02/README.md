# Experiment 02: CSS Styling and Layouts

## Objective
Practice six ways to style and lay out web pages: external, internal, and inline CSS; selectors; Flexbox and Grid; and transitions/animations.

## Parts

1. `parta/` — external stylesheet and reusable rules.
2. `partb/` — page-level internal styles.
3. `partc/` — inline styles and a short comparison.
4. `partd/` — selectors, specificity, pseudo-classes, and pseudo-elements.
5. `parte/` — responsive Flexbox and CSS Grid layouts.
6. `partf/` — transitions and keyframe animation, with reduced-motion support.

Open each HTML file directly in a browser. No build tools or dependencies are required.
